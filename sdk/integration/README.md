
# IntegrationLib SDK

## Описание
Динамическая библиотека численного интегрирования на C++20.

## Функции

- rectangle(f, a, b, n) — метод средних прямоугольников.
- trapezoid(f, a, b, n) — метод трапеций.
- simpson(f, a, b, n) — метод Симпсона.
- integrationError(approximate, exact) — абсолютная погрешность.

## Параметры

- f — указатель на функцию double(double).
- a, b — границы интегрирования.
- n — количество интервалов разбиения.
- approximate — приближённое значение.
- exact — точное значение.

## Ограничения

- n должно быть положительным.
- Для метода Симпсона n должно быть чётным.
- a и b должны быть конечными числами.
- f не должен быть nullptr.

## Ошибки

При некорректных аргументах возвращается NaN.
Исключения C++ не передаются через границу DLL.

## Подключение

Неявное:
подключить integration.h и IntegrationLib.lib.

Явное:
использовать LoadLibrary и GetProcAddress.

Для запуска требуется IntegrationLib.dll.
Архитектура сборки: x64.
