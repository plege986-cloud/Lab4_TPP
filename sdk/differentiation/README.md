# DifferentiationLib — бібліотека чисельного диференціювання

## 1. Призначення

Динамічна бібліотека DifferentiationLib призначена для наближеного обчислення похідних математичних функцій засобами мови C++20.

## 2. Функції бібліотеки

- `forwardDifference(f, x, h)` — обчислення першої похідної методом правої різниці.
- `backwardDifference(f, x, h)` — обчислення першої похідної методом лівої різниці.
- `centralDifference(f, x, h)` — обчислення першої похідної методом центральної різниці.
- `secondDerivative(f, x, h)` — обчислення другої похідної.

## 3. Параметри

- `f` — вказівник на функцію типу `double(double)`.
- `x` — точка обчислення похідної.
- `h` — крок чисельного диференціювання.

Усі функції повертають значення типу `double`.

## 4. Обмеження

- Вказівник `f` не може дорівнювати `nullptr`.
- Крок `h` повинен бути додатним і скінченним.
- Значення `x` повинно бути скінченним.

## 5. Обробка помилок

У разі некоректних аргументів функції повертають `NaN`. Винятки C++ перехоплюються всередині бібліотеки та не передаються через межу DLL.

## 6. Підключення бібліотеки

**Неявне зв'язування:** підключення заголовкового файлу `differentiation.h` та бібліотеки імпорту `DifferentiationLib.lib`.

**Явне зв'язування:** використання функцій Windows API `LoadLibrary()` та `GetProcAddress()`.

Для виконання програми необхідний файл `DifferentiationLib.dll`.

## 7. Склад SDK

- `differentiation.h` — заголовковий файл.
- `DifferentiationLib.lib` — бібліотека імпорту.
- `DifferentiationLib.dll` — динамічна бібліотека.
- `README.md` — документація.

Платформа: Windows x64. Мова програмування: C++20.
